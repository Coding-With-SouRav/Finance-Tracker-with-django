# Finance-Tracker-with-django

## How to run:
1. downdload this Zip Folder ==> Extract
2. install this requiremnts in terminal ```pip install Django==4.2.20```
3. run ```server.py``` file using ```python server.py``` command
4. after running the server file,,,  run ```index.html``` file in liveserver or any mode
